Zynth deploys to Cloudflare's edge network with a single command.

## Prerequisites

1. [Cloudflare account](https://dash.cloudflare.com/sign-up)
2. Wrangler authenticated: `bunx wrangler login`

## Deploy

```bash
bun run deploy
```

This deploys:
- **API** to Cloudflare Workers
- **Web** to Cloudflare Pages

## First Deployment

On first deploy, Cloudflare creates the D1 database and KV namespace automatically based on `wrangler.toml`.

After deploying, run migrations on production:

```bash
cd apps/api
bun run db:migrate:prod
```

## Environment Variables

### Production Secrets

Set secrets via Wrangler CLI:

```bash
cd apps/api

# Auth secrets
bunx wrangler secret put BETTER_AUTH_SECRET

# OAuth (if enabled)
bunx wrangler secret put GOOGLE_CLIENT_ID
bunx wrangler secret put GOOGLE_CLIENT_SECRET
bunx wrangler secret put GITHUB_CLIENT_ID
bunx wrangler secret put GITHUB_CLIENT_SECRET

# Email (if enabled)
bunx wrangler secret put RESEND_API_KEY
```

### Web Environment

For the frontend, set variables in Cloudflare Pages dashboard or `wrangler.toml`:

```toml
[vars]
VITE_API_URL = "https://api.yourdomain.com"
```

## Custom Domains

### API (Workers)

1. Go to Workers & Pages > your-api > Settings > Domains
2. Add custom domain (e.g., `api.yourdomain.com`)

### Web (Pages)

1. Go to Workers & Pages > your-web > Custom domains
2. Add custom domain (e.g., `yourdomain.com`)

## Configuration

Deployment settings are in `wrangler.toml`:

```toml title="apps/api/wrangler.toml"
name = "my-app-api"
compatibility_date = "2024-01-01"

[[d1_databases]]
binding = "DB"
database_name = "my-app-db"
database_id = "auto-generated-on-deploy"

[[kv_namespaces]]
binding = "KV"
id = "auto-generated-on-deploy"
```

## Preview Deployments

Deploy to a preview environment:

```bash
cd apps/api
bunx wrangler deploy --env preview

cd apps/web
bunx wrangler pages deploy dist --branch preview
```

## Rollbacks

Cloudflare keeps deployment history. To rollback:

1. Go to Workers & Pages > your-app > Deployments
2. Click on a previous deployment
3. Click "Rollback to this deployment"

## Monitoring

- **Logs**: Workers & Pages > your-app > Logs
- **Analytics**: Workers & Pages > your-app > Analytics
- **Errors**: Real-time error tracking in the dashboard

## CI/CD

Example GitHub Actions workflow:

```yaml title=".github/workflows/deploy.yml"
name: Deploy
on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v1
      - run: bun install
      - run: bun run build
      - run: bun run deploy
        env:
          CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}
```

Create an API token at Cloudflare dashboard > My Profile > API Tokens with "Edit Workers" permissions.
