## Shared Config

`packages/config/src/index.ts` contains public configuration shared across apps.

```ts
export const config = {
  appName: 'zynth',
  tagline: 'Ship in 60 Seconds, Not 3 Days',
  description: 'Cloudflare Workers fullstack template',

  domains: {
    web: 'template.zynth.dev',
  },
  webUrl: 'https://template.zynth.dev',

  auth: {
    enableMagicLink: true,
    enableGoogleOAuth: true,
    enableGitHubOAuth: false,
  },

  // Public navigation (Header component)
  nav: [
    { label: 'Home', href: '/', newTab: false },
    { label: 'Docs', href: '/docs', newTab: true },
  ],

  // ...
}
```

### Navigation `newTab` Property

The `newTab` property controls how links are rendered in the header:

| Value | Behavior |
|-------|----------|
| `false` | Uses TanStack Router `<Link>` for client-side navigation |
| `true` | Uses `<a target="_blank">` for external/separate-worker links |

Use `newTab: true` for:
- Links to different workers (e.g., docs served by a separate worker)
- External URLs
- Links that should open in a new browser tab

<Callout type="warn">
Everything in this file is public. Never put API keys or secrets here.
</Callout>

## Environment Variables

### Deployment

```bash
# Required for deployment
CLOUDFLARE_API_TOKEN=xxx    # API token with Workers, KV, D1, DNS permissions
CLOUDFLARE_ZONE_ID=xxx      # Zone ID from Cloudflare Dashboard → your-domain → Overview
ALCHEMY_PASSWORD=xxx        # Password for Alchemy state encryption
```

### API (`apps/api/.dev.vars`)

```bash
# Required
BETTER_AUTH_SECRET=your-secret-key

# OAuth (optional)
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=

# Email service (optional)
RESEND_API_KEY=
```

### Web

Frontend uses `VITE_` prefixed variables:

```bash
# apps/web/.env
VITE_API_URL=http://localhost:8787
```

Access in code:

```ts
const apiUrl = import.meta.env.VITE_API_URL
```

## Alchemy Configuration

This project uses [Alchemy](https://alchemy.run) for infrastructure-as-code deployment. Each app has an `alchemy.run.ts` file.

### Example (`apps/web/alchemy.run.ts`)

```ts
import { DnsRecords, Vite } from 'alchemy/cloudflare'

// Create DNS record
await DnsRecords('web-dns', {
  zoneId: process.env.CLOUDFLARE_ZONE_ID,
  records: [
    {
      type: 'A',
      name: 'subdomain',
      content: '192.0.2.1',  // Proxied - actual IP doesn't matter
      proxied: true,
      ttl: 1,
    },
  ],
})

// Deploy Vite app
export const web = await Vite('web', {
  name: 'my-app-web',
  entrypoint: './worker.ts',
  routes: [
    { pattern: 'yourdomain.com' },
    { pattern: 'yourdomain.com/*' },
  ],
})
```

## Turborepo

`turbo.json` configures task pipelines:

```json
{
  "tasks": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": ["dist/**"]
    },
    "dev": {
      "cache": false,
      "persistent": true
    },
    "deploy": {
      "dependsOn": ["build"]
    }
  }
}
```

## TypeScript

Root `tsconfig.json` with shared settings:

```json
{
  "compilerOptions": {
    "strict": true,
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler"
  }
}
```

Each app extends with its own config.

## Biome (Linting)

`biome.json` at root:

```json
{
  "linter": {
    "enabled": true,
    "rules": {
      "recommended": true
    }
  },
  "formatter": {
    "indentStyle": "tab"
  }
}
```

Pre-commit hook runs `bun x ultracite fix` automatically.
