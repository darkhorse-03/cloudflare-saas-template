## Shared Config

`packages/config/src/index.ts` contains public configuration shared across apps.

```ts
export const config = {
  appName: 'zynth',
  tagline: 'Ship in 60 Seconds',
  description: 'Cloudflare Workers fullstack template',

  domains: {
    web: 'example.com',
    docs: 'docs.example.com',
  },
  webUrl: 'https://example.com',

  auth: {
    enableMagicLink: true,
    enableGoogleOAuth: true,
    enableGitHubOAuth: false,
  },

  nav: [
    { label: 'Home', href: '/' },
    { label: 'Features', href: '/features' },
  ],

  // ...
}
```

<Callout type="warn">
Everything in this file is public. Never put API keys or secrets here.
</Callout>

## Environment Variables

### API (`apps/api/.dev.vars`)

```bash
# Required
BETTER_AUTH_SECRET=your-secret-key

# OAuth (optional)
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=

# Email service (optional)
RESEND_API_KEY=
```

### Web

Frontend uses `VITE_` prefixed variables:

```bash
# apps/web/.env
VITE_API_URL=http://localhost:8787
```

Access in code:

```ts
const apiUrl = import.meta.env.VITE_API_URL
```

## Wrangler Configuration

### API Worker (`apps/api/wrangler.toml`)

```toml
name = "my-app-api"
main = "src/index.ts"
compatibility_date = "2024-01-01"

# D1 Database
[[d1_databases]]
binding = "DB"
database_name = "my-app-db"
database_id = "xxx"  # Generated on first deploy

# KV for rate limiting
[[kv_namespaces]]
binding = "KV"
id = "xxx"  # Generated on first deploy

# Environment variables
[vars]
ENVIRONMENT = "production"
```

### Preview Environment

```toml
[env.preview]
name = "my-app-api-preview"

[[env.preview.d1_databases]]
binding = "DB"
database_name = "my-app-db-preview"
database_id = "xxx"
```

## Turborepo

`turbo.json` configures task pipelines:

```json
{
  "tasks": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": ["dist/**"]
    },
    "dev": {
      "cache": false,
      "persistent": true
    },
    "deploy": {
      "dependsOn": ["build"]
    }
  }
}
```

## TypeScript

Root `tsconfig.json` with shared settings:

```json
{
  "compilerOptions": {
    "strict": true,
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler"
  }
}
```

Each app extends with its own config.

## Biome (Linting)

`biome.json` at root:

```json
{
  "linter": {
    "enabled": true,
    "rules": {
      "recommended": true
    }
  },
  "formatter": {
    "indentStyle": "tab"
  }
}
```

Pre-commit hook runs `bun x ultracite fix` automatically.
